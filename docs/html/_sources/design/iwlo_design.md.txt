# Intensity-Weighted Log-Odds (IWLO) Probability Update

## Overview

IWLO는 ==Log-Odds Bayesian==과 ==Weighted Average== 방식의 장점을 결합한 확률 업데이트 방법이다.

**Core Idea**: Intensity 정보를 sigmoid 함수로 변환하여 log-odds 업데이트 강도를 조절하고, 관측 횟수에 따라 learning rate를 감쇠시켜 자연스러운 수렴을 달성한다.

---

## 1. Background

### Limitations of Existing Methods

| Method | Advantages | Limitations |
|--------|------------|-------------|
| **Log-Odds** | Mathematical rigor, fast change detection | Ignores intensity, saturation risk |
| **Weighted Average** | Uses intensity, natural convergence | Weak Bayesian justification, slow change detection |

### IWLO Design Goals

1. Intensity 정보를 지속적으로 활용
2. Log-odds 기반 Bayesian 업데이트 유지
3. 관측 횟수에 따른 신뢰도 반영
4. 환경 변화에 대한 적절한 반응성 유지
5. Saturation 방지

---

## 2. Mathematical Formulation

### 2.1 Probability-Log-Odds Transformation

**Definition:**

$$L = \log\left(\frac{P}{1-P}\right)$$

$$P = \frac{1}{1 + e^{-L}}$$

**Property**: Log-odds 공간에서 업데이트는 ==덧셈 연산==으로 이루어진다.

---

### 2.2 Intensity-to-Weight Transformation

**Definition:**

$$w(I) = \begin{cases}
0 & \text{if } I \leq I_{th} \\
\sigma\left(\gamma \cdot \left(\frac{I - I_{th}}{I_{max} - I_{th}} - 0.5\right)\right) & \text{otherwise}
\end{cases}$$

where $\sigma(x) = \frac{1}{1 + e^{-x}}$ (sigmoid function)

**Parameters:**

| Parameter | Symbol | Default | Range | Description |
|-----------|--------|---------|-------|-------------|
| Intensity threshold | $I_{th}$ | 35 | [0, 100] | 최소 유효 intensity |
| Maximum intensity | $I_{max}$ | 255 | [100, 255] | 정규화 기준 최대값 |
| Sharpness | $\gamma$ | 0.1 | [0.1, 5.0] | Sigmoid 기울기 |

**Characteristics:**
- $I \leq I_{th}$: $w = 0$ (무시)
- $I = I_{th} + 0.5(I_{max} - I_{th})$: $w = 0.5$ (중간)
- $I \to I_{max}$: $w \to 1$ (최대)

---

### 2.3 Learning Rate Decay

**Definition:**

$$\alpha(n) = \max\left(\alpha_{min}, \frac{1}{1 + \lambda \cdot n}\right)$$

**Parameters:**

| Parameter | Symbol | Default | Range | Description |
|-----------|--------|---------|-------|-------------|
| Decay rate | $\lambda$ | 0.1 | [0.05, 0.5] | 감쇠 속도 |
| Minimum alpha | $\alpha_{min}$ | 0.3 | [0.01, 0.5] | 최소 learning rate |

**Characteristics:**
- $n=0$: $\alpha = 1.0$ (첫 관측)
- $n \to \infty$: $\alpha \to \alpha_{min}$ (환경 변화 감지 유지)

---

### 2.4 Adaptive Scaling (Bidirectional Protection)

**Occupied Update** (when $I > I_{th}$):

$$s_{occ} = \begin{cases}
\frac{P}{P_{th}} \cdot r_{max} & \text{if } P < P_{th} \\
1.0 & \text{otherwise}
\end{cases}$$

**Free Update** (when $I \leq I_{th}$):

$$s_{free} = \begin{cases}
r_{max} + (1 - r_{max})(1 - f_p) & \text{if } P > 1 - P_{th} \\
1.0 & \text{otherwise}
\end{cases}$$

where $f_p = \frac{P - (1 - P_{th})}{P_{th}}$

**Parameters:**

| Parameter | Symbol | Default | Description |
|-----------|--------|---------|-------------|
| Adaptive threshold | $P_{th}$ | 0.5 | 보호 시작 확률 |
| Maximum ratio | $r_{max}$ | 0.3 | 최대 억제 비율 |

**Purpose**: 이미 ==free로 분류된 영역==에서 노이즈성 occupied 업데이트를 억제하고, ==occupied로 분류된 영역==에서 노이즈성 free 업데이트를 억제한다.

---

### 2.5 Update Formula

**Occupied Update** (when $I > I_{th}$):

$$\Delta L_{occ} = L_{occ} \times w(I) \times \alpha(n) \times s_{occ}$$

**Free Update** (when $I \leq I_{th}$):

$$\Delta L_{free} = L_{free} \times \alpha(n) \times s_{free}$$

**Application:**

$$L_{new} = \text{clamp}(L_{old} + \Delta L, L_{min}, L_{max})$$

**Parameters:**

| Parameter | Symbol | Default | Range | Description |
|-----------|--------|---------|-------|-------------|
| Occupied log-odds | $L_{occ}$ | 3.5 | [0.5, 5.0] | Occupied 업데이트 강도 |
| Free log-odds | $L_{free}$ | -3.0 | [-5.0, -0.5] | Free 업데이트 강도 |
| Saturation min | $L_{min}$ | -10.0 | [-10.0, 0.0] | 하한 ($P \approx 0.00005$) |
| Saturation max | $L_{max}$ | 10.0 | [2.0, 10.0] | 상한 ($P \approx 0.99995$) |

## 3. Algorithm Pseudocode

```
ALGORITHM: IWLO_Update
INPUT:
  - point (x, y, z): 복셀 좌표
  - intensity I: 소나 반사 강도 [0, 255]
  - L_current: 현재 log-odds 값
  - n: 관측 횟수
  - params: {I_th, I_max, γ, λ, α_min, P_th, r_max, L_occ, L_free, L_min, L_max}
OUTPUT: L_new (새로운 log-odds 값)

1. DETERMINE update type:
   IF I <= I_th THEN
     is_occupied := FALSE
     w := 0
   ELSE
     is_occupied := TRUE
     normalized := (I - I_th) / (I_max - I_th)
     w := sigmoid(γ × (normalized - 0.5))
   ENDIF

2. COMPUTE learning rate:
   α := max(α_min, 1 / (1 + λ × n))

3. COMPUTE adaptive scale:
   P_current := sigmoid(L_current)

   IF adaptive_enabled THEN
     IF is_occupied AND P_current < P_th THEN
       scale := (P_current / P_th) × r_max
     ELSE IF NOT is_occupied AND P_current > (1 - P_th) THEN
       f_p := (P_current - (1 - P_th)) / P_th
       scale := r_max + (1 - r_max) × (1 - f_p)
     ELSE
       scale := 1.0
     ENDIF
   ELSE
     scale := 1.0
   ENDIF

4. COMPUTE delta:
   IF is_occupied THEN
     ΔL := L_occ × w × α × scale
   ELSE
     ΔL := L_free × α × scale
   ENDIF

5. APPLY update:
   L_new := clamp(L_current + ΔL, L_min, L_max)

6. RETURN L_new
```

## 4. Parameter Tuning Guide

### 4.1 Sharpness ($\gamma$)

| Value | Behavior |
|-------|----------|
| High (4-5) | Intensity에 민감, binary classification에 가까움 |
| Low (0.1-1) | Intensity에 둔감, smooth transition |

### 4.2 Decay Rate ($\lambda$)

| Value | Behavior |
|-------|----------|
| High (0.3-0.5) | 빠른 수렴, 환경 변화 감지 약화 |
| Low (0.05-0.1) | 느린 수렴, 환경 변화 감지 유지 |

### 4.3 Minimum Alpha ($\alpha_{min}$)

| Value | Behavior |
|-------|----------|
| High (0.2-0.5) | 환경 변화에 빠른 반응 |
| Low (0.01-0.1) | 안정적이지만 느린 변화 감지 |
